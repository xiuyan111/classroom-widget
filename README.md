# 教室今日课表 · Windows 桌面浮窗

透明桌面课表工具，可离线查看教室当天的课程安排。

## 下载完整版

**[点击直接下载 Windows 完整免安装版](https://github.com/xiuyan111/classroom-widget/releases/latest/download/ClassroomWidget-Windows.zip)**

[打开版本下载页和使用说明](https://github.com/xiuyan111/classroom-widget/releases/latest)

## 使用方法

1. 下载 `ClassroomWidget-Windows.zip`。
2. 将压缩包完整解压到一个文件夹。
3. 双击 `ClassroomWidget.exe`，首次运行时选择教室。
4. 拖动标题调整位置；右上角“⋯”可调整透明度、大小和置顶。

适用于 Windows 10 / 11，需要系统自带的 .NET Framework 4.x 桌面组件。无需安装 Node.js。

完整包包含程序、运行配置和中文使用说明。课表数据已内置，无需另外下载。

## 功能

- 透明桌面浮窗与当日课表。
- 教室切换、当前时段高亮。
- 大小、透明度、始终置顶和收起课表。
- 自动保存教室与界面设置。

## 课表说明

当前内置 2026–2027 S1 周课表，不自动连接小程序后台。暂不包含临时调课、借用、节假日和补课安排；更新课表后需替换程序。“空闲”仅表示课表未安排课程，不代表现场无人或已允许借用。

当前程序未做数字签名。更详细的操作及限制请查看压缩包内的 `使用说明.md`。
